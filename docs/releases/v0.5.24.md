Changes since / 相较于 [v0.5.23](https://github.com/daife/Asayn/releases/tag/v0.5.23) (`f81da31`).

## 更新

- 新增 `view_image`，支持读取工作区内的 PNG、JPEG、GIF、WebP 图片，适配 DeepSeek Chat Completions、Responses 和 ChatGPT 订阅模式。CLI、桌面端及子 Agent 共用，图像数据随会话保存；需使用支持视觉输入的模型。
- 支持运行中引导：Enter 在当前批工具调用完成后插入消息，Tab 将消息排到下一轮；Esc 优先取消最后一条排队消息，队列为空时中断当前轮次。
- TUI 在工具运行期间显示调用参数，便于查看正在执行的操作。

## 修复

- 为 TUI 的 Enter 发送增加 0.5 秒保护：回车前后 0.5 秒内有其他回车，或等待期间继续编辑，则取消发送并保留输入，避免未标记的多行粘贴被逐行误发送。适用于普通消息及运行中的引导消息；正常 Enter 发送延迟约 0.5 秒。
- 修复 TUI 模型配置页中 Skills/MCP 选择标记与实际切换对象错位、末项无法正常选择的问题。
- 桌面浏览器预览配置不再默认启用 codegraph，与默认 MCP 配置保持一致。

## Updates

- Added `view_image` for workspace PNG, JPEG, GIF, and WebP images across DeepSeek Chat Completions, Responses, and ChatGPT subscription mode. CLI, desktop, and sub-agents share the tool; image data persists in sessions. Requires a vision-capable model.
- Added live steering: Enter inserts a message after the current tool batch; Tab queues it for the next turn. Esc cancels the last queued message first, or interrupts the current turn when the queue is empty.
- TUI now shows tool arguments while calls are running.

## Fixes

- Protected TUI Enter submission with a 0.5-second quiet period. Nearby Enters or continued editing cancel submission and retain the draft, preventing unmarked multiline pastes from sending each line. Applies to ordinary messages and live steering; normal Enter submission waits about 0.5 seconds.
- Fixed misaligned Skills/MCP selection markers and toggle targets, including last-item navigation, in the TUI model configuration picker.
- Disabled codegraph in the desktop browser preview defaults to match the default MCP configuration.
