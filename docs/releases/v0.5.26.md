## 修复 / Fixes

- 修复 ChatGPT OAuth 订阅会话回传历史推理项时可能出现的 `Unknown parameter: 'input[N].status'` HTTP 400 错误。
- Fix HTTP 400 `Unknown parameter: 'input[N].status'` errors when ChatGPT OAuth subscription sessions replay historical reasoning items.
- 在构造订阅请求时移除 reasoning 项的 `status`，保留加密推理内容及其他字段；已有会话无需迁移，标准 Responses 请求保持原有行为。
- Strip reasoning `status` when building subscription requests while preserving encrypted reasoning and other fields. Existing sessions work without migration; standard Responses requests retain their existing behavior.
