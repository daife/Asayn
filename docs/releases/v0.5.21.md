## 修复：ChatGPT 订阅流式回复消失

- 修复 Responses 流式事件合并中的内容丢失：终止事件的 `output` 缺失或为空时，旧代码会用空回复覆盖已收到的正文，导致界面刷新后文字消失。现在保留并合并前面收到的输出项和文本增量。
- 输出项按 `output_index` 排序、去重，避免项目完成事件与终止事件重复拼接正文或工具调用；保留加密推理上下文和流式推理文本。
- 失败、未完成或格式异常的终止事件仍返回错误，同时保留已输出的文字，不将部分输出误判为成功。
- 同时修复普通 Responses 模式的相同处理路径，Chat Completions 协议不受影响。
- 新增回归测试，覆盖空/缺失终止输出、异常终止、输出项排序与去重，以及完整的“流式显示 → 会话保存/重载 → 下一轮历史”流程。

升级后无需重新配置 Provider 或重新登录，已有 ChatGPT 订阅凭据继续使用。此修复不会恢复旧版本已丢失的回复。

## Fix: disappearing ChatGPT subscription replies

- Fixed Responses stream assembly replacing previously streamed text with an empty final response when the terminal envelope omitted its output items.
- Preserve streamed text, completed output items, tool calls, and reasoning context; assemble items in output-index order without duplicating final snapshots.
- Failed, incomplete, and malformed terminal events retain partial text while still reporting an error.
- Added stream regression tests and an agent/session round-trip test that verifies the next request retains the previous reply. Both subscription and ordinary Responses modes use the fix; Chat Completions behavior is unchanged.

Existing provider settings and saved subscription credentials remain usable. Replies already lost by earlier versions cannot be recovered by this update.
