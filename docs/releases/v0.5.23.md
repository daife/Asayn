## 调整：关闭工具输出自动截断

- 文件读取、目录列表、搜索、技能读取、同步/异步 Shell、MCP 和子 Agent 查询不再按行数截断返回内容。
- 移除内容搜索的 200 条匹配上限，并支持超过 1 MiB 的文本行，避免搜索结果被静默遗漏。
- 旧的 `max_output_lines` 配置仍可加载，但不再限制工具输出。
- 保留 `file_read` 显式行范围和二进制/无扩展名文件预览机制；需要读取此类文件全文时可设置 `force_binary=true`。

## Change: disable automatic tool output truncation

- Removed line-based output truncation from file reads, directory listings, searches, skills, synchronous/asynchronous Shell results, MCP calls, and sub-agent queries.
- Removed the 200-match content-search cap and support text lines larger than 1 MiB without silently losing subsequent matches.
- Existing `max_output_lines` settings remain loadable but no longer limit tool results.
- Explicit file line ranges and binary/extensionless file previews remain available; use `force_binary=true` to read those files as text.
