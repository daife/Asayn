## 更新内容

### 新增 OpenAI Responses 与订阅 Responses

- Provider 新增 `api_type = "responses"`，支持普通 OpenAI Responses 协议，保留 Chat Completions 兼容性；主 agent、子 agent、压缩 agent 均可选择。
- 新增 `api_type = "subscription_responses"`，通过官方 Sign in with ChatGPT OAuth 流程使用符合条件的 ChatGPT 订阅额度，无需 API Key。
- 新增 CLI 命令：`asayn subscription login [账号标签]`、`asayn subscription models [账号标签]`、`asayn subscription logout [账号标签]`，支持账号隔离、实时模型查询和会话撤销。
- 登录包含 PKCE、state、nonce、ID Token 签名及身份验证，复用已签发的 client ID 和稳定 host ID。凭据单独保存在本机，支持自动刷新、refresh token 轮换及跨进程刷新锁。
- 订阅调用固定使用公开 `/v1/responses`，强制 `store=false`、`stream=true`，将 system 提示转换为 developer 消息，并携带完整本地历史。仅收到 `response.completed` 才成功；额度限制和不完整响应会返回错误，不会自动切换 API 付费。
- Responses 支持工具调用续接、加密推理上下文和流式用量统计；支持固定的 `prompt_cache_key` 跨会话及子 agent 复用。
- 补充中英文配置文档与请求、终止事件、凭据刷新及配置校验测试。

### 开始使用订阅额度

先执行：

```sh
asayn subscription login personal
asayn subscription models personal
```

在 `~/.Asayn/api_config.toml` 添加：

```toml
[providers.ChatGPT]
api_type = "subscription_responses"
subscription_account = "personal"
timeout_seconds = 120
allowed_models = ["替换为 models 命令返回的 slug"]
```

然后将 agent 的 `provider` 设为 `ChatGPT`，`model` 设为实际 slug。桌面版共用本地配置和凭据，需先通过 CLI 登录。请勿配置 `api_key`。省略账号标签时使用 `default`，不同账号/工作区请使用不同标签。

此能力受官方预览限制、账号/工作区资格、地区及授权范围约束。Plus 的五小时订阅额度在使用该订阅的应用之间共享。真实授权和额度可用性需由本人登录确认。详情见 [中文使用说明](https://github.com/daife/Asayn/blob/v0.5.20/README.zh-CN.md#使用-chatgpt-订阅额度订阅-responses)及[官方预览限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。

## What's new

- Added configurable OpenAI Responses support alongside Chat Completions, including tool continuation, encrypted reasoning context, streaming usage, and a stable optional prompt cache key.
- Added `subscription_responses` for eligible ChatGPT plan usage through official Sign in with ChatGPT OAuth, with CLI login, account-specific model discovery, and logout commands.
- Added protected local credentials, PKCE/OIDC validation, reusable client/host identity, automatic refresh token rotation, and cross-process refresh locking.
- Subscription inference uses the public Responses endpoint with full local history, `store=false`, and `stream=true`. System prompts become developer messages. Incomplete streams and plan-limit errors fail explicitly without switching billing paths.
- Updated English/Chinese setup documentation and regression coverage. Desktop uses the same credentials after CLI sign-in.
