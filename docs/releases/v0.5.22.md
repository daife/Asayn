## 调整：关闭自动 diff

- 同步 Shell 命令执行前后不再自动扫描工作目录或生成文件差异。
- 命令输出不再自动附加 `File changes:` diff，减少目录扫描和差异计算开销。
- 仍可通过显式执行 `git diff` 等命令查看修改。

## Change: disable automatic diffs

- Removed automatic workdir snapshots and file diff generation around synchronous Shell commands.
- Command output no longer includes an automatically appended `File changes:` diff, avoiding directory scanning and diff computation overhead.
- Changes can still be inspected by explicitly running commands such as `git diff`.
