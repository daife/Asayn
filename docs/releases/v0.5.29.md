## 修复 / Fix

- 修复 `shell_run_sync` 将 `timeout_sec` 设为 0 或负数时仍被默认超时中断的问题；现在会一直等待至命令完成或取消。
- Honor zero and negative shell timeouts as unlimited waits, while preserving user cancellation and parent cancellation.
- 移除 Agent 对工具调用额外施加的截止时间，避免工具执行被独立的外层超时打断。

## 更新 / Update

- API `timeout_seconds` 继续仅用于 API 响应头等待和流式空闲超时；Shell 执行时长由 `timeout_sec` 控制，省略时默认 60 秒。
- Clarify the shell tool timeout parameter description. Release builds remain CLI-only.
